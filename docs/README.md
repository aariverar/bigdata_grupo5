## Cómo usar este material

1. Cada archivo cubre un tema completo con:
   - **Definición** y concepto clave
   - **Participantes / estructura**
   - **Tipos** y diferencias
   - **Costos** y fórmulas
   - **Ejemplo numérico paso a paso**
   - **Preguntas típicas de examen oral** con respuestas modelo
   - **Frases clave** para usar en el examen
   - **Errores comunes** a evitar

2. Navega al tema desde la tabla de arriba o directamente desde la carpeta `finanzas-aplicadas/`.
